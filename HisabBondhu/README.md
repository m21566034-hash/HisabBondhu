# হিসাববন্ধু (HisabBondhu)

বাংলাদেশের পাইকারি দোকানের জন্য নেটিভ অ্যান্ড্রয়েড ব্যবসা-ব্যবস্থাপনা অ্যাপ।
Kotlin + Jetpack Compose (Material 3) · Room (অফলাইন) · Firebase Auth + Firestore (ক্লাউড সিঙ্ক) · WorkManager

- Application ID: `com.techfix.HisabBondhu`
- Firebase প্রজেক্ট: `hisab-c3d8d`
- Min SDK 26 (Android 8.0), Target/Compile SDK 35

## ⚠ বর্তমান অবস্থা (সৎ হিসাব)

এই কোড যে ক্লাউড-সেশনে লেখা হয়েছে সেখান থেকে Maven/Google/Android SDK সার্ভারে যাওয়া যায় না এবং Firestore এমুলেটর নামানো যায় না। তাই:

| বিষয় | অবস্থা |
|---|---|
| আর্থিক হিসাব (`core/Calc.kt`, `Fmt.kt`, `DateRanges.kt`) | কম্পাইল করে ১৫টি ইউনিট টেস্ট চালানো হয়েছে, সব পাস |
| বাকি অ্যান্ড্রয়েড কোড (UI, Room, Sync, ইনভয়েস রেন্ডার) | লেখা ও হাতে রিভিউ করা হয়েছে, **কিন্তু এখনো কম্পাইল ও চালানো হয়নি** |
| APK | **তৈরি হয়নি।** নিচের নির্দেশ দিয়ে আপনার কম্পিউটারে বিল্ড করুন |
| Firestore Security Rules | লেখা আছে, `rules-test/` এ দুই-অ্যাকাউন্ট টেস্ট আছে, **চালানো হয়নি** (এমুলেটর ডাউনলোড ব্লক ছিল) |
| WhatsApp শেয়ার, লগইন, অফলাইন সিঙ্ক | ডিভাইসে পরীক্ষা হয়নি |

প্রথম বিল্ডে কিছু কম্পাইল এরর আসতে পারে। সেগুলো ঠিক করে নিন (বা এরর আমাকে পাঠান)। নিচের টেস্ট লিস্ট শেষ না করে আসল ব্যবসায় ব্যবহার করবেন না।

## ১. Firebase সেটআপ

1. [Firebase Console](https://console.firebase.google.com) → প্রজেক্ট `hisab-c3d8d`।
2. **Authentication → Sign-in method → Google** চালু করুন (সাপোর্ট ইমেইল দিন)।
3. **Project settings → Your apps → Android (`com.techfix.HisabBondhu`) → Add fingerprint**:
   - ডিবাগ কী-র SHA-1: `./gradlew signingReport` (Variant: `debug`)
   - রিলিজ কী-র SHA-1 আলাদা করে যোগ করুন (প্লে স্টোর ব্যবহার করলে Play App Signing-এর SHA-1-ও)।
4. SHA-1 যোগ করার পর **নতুন `google-services.json` ডাউনলোড** করে `app/google-services.json` বদলান। (শুধু তখনই ফাইলে Android OAuth ক্লায়েন্ট আসে; Web ক্লায়েন্ট `default_web_client_id` আগেই আছে।)
5. **Firestore Database** তৈরি করুন (Production mode), তারপর রুলস দিন:
   ```
   npm i -g firebase-tools && firebase login
   firebase deploy --only firestore:rules,firestore:indexes --project hisab-c3d8d
   ```
   (অথবা Console-এ `firestore.rules` এর লেখা পেস্ট করুন।) **রুলস না দিলে Firestore খোলা বা বন্ধ থাকবে। ডিপ্লয় করা বাধ্যতামূলক।**
6. Firebase Storage লাগে না, চালু করবেন না (লোগো/ছবি ছোট করে রেকর্ডের ভেতরেই থাকে)।

## ২. বিল্ড

**Java সংস্করণ:** JDK **17** (বা 21) লাগবে। JDK 8/11 বা 22+ হলে বিল্ড ব্যর্থ হবে। প্রজেক্টে Gradle **8.9** wrapper দেওয়া আছে (AGP 8.7.3-এর জন্য ন্যূনতম), তাই আলাদা Gradle ইনস্টল লাগবে না। Android SDK (platform 35) লাগবে; `local.properties`-এ `sdk.dir=...` দিন, নাহলে Android Studio নিজে দেবে।

একটি কমান্ডে (Java সংস্করণ নিজেই যাচাই করে, ভুল হলে থেমে বলে দেয়):

```
Linux / macOS :  ./build-debug.sh            # ইউনিট টেস্ট + ডিবাগ APK
Windows       :  build-debug.bat
```
APK: `app/build/outputs/apk/debug/app-debug.apk`

JAVA_HOME ঠিক করে সরাসরি চালাতে চাইলে:

```
# Linux
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64 && ./gradlew testDebugUnitTest assembleDebug
# macOS
export JAVA_HOME=$(/usr/libexec/java_home -v 17) && ./gradlew testDebugUnitTest assembleDebug
# Windows (Android Studio-র সাথে আসা JDK 17+)
set "JAVA_HOME=C:\Program Files\Android\Android Studio\jbr" && gradlew.bat testDebugUnitTest assembleDebug
```
Android Studio-তে: Settings → Build Tools → Gradle → **Gradle JDK = jbr-17 (বা 17/21)**।

### GitHub Codespaces-এ বিল্ড (নিজের কম্পিউটারে Android SDK না থাকলে)

প্রজেক্টে `.devcontainer/` আছে: Java **17** ও Android SDK 35 নিজে বসে যায়।

1. প্রজেক্ট একটি **প্রাইভেট** GitHub রিপোজিটরিতে পুশ করুন (`app/google-services.json`-এ আপনার Firebase API কী আছে)।
2. Code → Codespaces → **Create codespace on main** (কমপক্ষে ৪ কোর/৮ GB মেশিন বেছে নিন)।
3. প্রথমবার তৈরির সময় SDK বসতে কয়েক মিনিট লাগে। শেষ হলে টার্মিনালে:
   ```
   ./build-debug.sh
   ```
4. বাঁয়ের ফাইল-তালিকায় `app/build/outputs/apk/debug/app-debug.apk` → ডান ক্লিক → **Download** → ফোনে নিয়ে ইনস্টল।

বিকল্প: `.github/workflows/build-apk.yml` আছে। `main`-এ পুশ করলে বা Actions ট্যাব থেকে **Run workflow** দিলে GitHub নিজেই বিল্ড করে; শেষে রান পেজের **Artifacts** থেকে `hisabbondhu-debug-apk` নামানো যায়। (এটি ডিবাগ APK; রিলিজ কী কখনো রিপোজিটরিতে রাখবেন না।)

### রিলিজ APK (ছোট সাইজ)

1. কী তৈরি: `keytool -genkeypair -v -keystore hisab.jks -alias hisab -keyalg RSA -keysize 2048 -validity 10000`
2. প্রজেক্ট রুটে `keystore.properties` বানান (কখনো কমিট করবেন না):
   ```
   storeFile=hisab.jks
   storePassword=...
   keyAlias=hisab
   keyPassword=...
   ```
3. `./build-debug.sh release` (Windows: `build-debug.bat release`) → `app/build/outputs/apk/release/app-release.apk`

### অ্যাপ সাইজ কমানোর ব্যবস্থা (করা আছে)

- R8 + resource shrinking (`isMinifyEnabled`, `isShrinkResources`), full mode
- শুধু বাংলা ও ইংরেজি লাইব্রেরি রিসোর্স রাখা হয়েছে
- অতিরিক্ত আইকন লাইব্রেরি/ইমেজ লাইব্রেরি/ফন্ট ফাইল/PDF লাইব্রেরি নেই; সিস্টেমের বাংলা ফন্ট ও Android Canvas ব্যবহার
- নেভিগেশন লাইব্রেরি, Hilt, Retrofit ইত্যাদি বাদ
- অপ্রয়োজনীয় META-INF ও ডিপেন্ডেন্সি মেটাডেটা বাদ
- ছবি ছোট করে (লোগো ২৪০px, পণ্য ৩৬০px, খরচের রসিদ ৭০০px) JPEG হিসেবে সংরক্ষণ
- সাইজ আরও কমাতে: Play Store-এ `.aab` দিন (`./gradlew bundleRelease`) অথবা ABI-ভিত্তিক APK। আমি প্রকৃত সাইজ মাপতে পারিনি, বিল্ড করে `app-release.apk` দেখে নিন। সাধারণত Compose + Firebase Auth + Firestore মিলিয়ে ৮–১৫ MB আশা করা যায়, এটা অনুমান।

## ৩. কীভাবে কাজ করে (সংক্ষেপে)

- **টাকা** সবসময় পয়সা (`Long`), **পরিমাণ** মিলি-ইউনিট (`Long`); কোথাও `Double` নেই।
- **ডাটা**: Room-ই মূল সোর্স। প্রতিটি লেখা একটি লেনদেনে (transaction) হয় এবং `Outbox`-এ জমা থাকে; WorkManager ইন্টারনেট পেলে Firestore-এ `set()` করে (স্থায়ী UUID আইডি, তাই পুনরায় পাঠালে ডুপ্লিকেট হয় না)।
- **পুল**: `updatedAt` কার্সর দিয়ে শুধু বদলানো ডকুমেন্ট আনে (Spark প্ল্যানের রিড বাঁচায়)। কোনো রিয়েলটাইম লিসেনার/পোলিং নেই; সিঙ্ক চলে লেখার পর, অ্যাপ খোলার সময়, আর ৬ ঘণ্টা পরপর।
- **বিল নম্বর**: `INV-YYMMDD-<৪ অক্ষরের ডিভাইস কোড>-<ক্রমিক>`, তাই একাধিক ডিভাইসেও মিলে যাওয়ার সম্ভাবনা নেই।
- **ইনভয়েস ছবি**: `render/DocRenderer.kt`, ১০৮০px প্রস্থ, উচ্চতা বিষয়বস্তু অনুযায়ী; ২৬০০px-এর বেশি হলে "বিল ১/২" ইত্যাদি ভাগে ভাগ হয়, প্রতিটিতে বিল নম্বর ও কাস্টমারের নাম থাকে, টোটাল কখনো ভাগ হয় না।
- **WhatsApp**: শেয়ার ইন্টেন্টে ছবি ও বার্তা সংযুক্ত হয়; মালিক নিজে পাঠান। অ্যাপ "পৌঁছেছে" দাবি করে না।
- **সংশোধন**: বিল বাতিল/ফেরত/পেমেন্ট রিভার্স সবই নতুন রেকর্ড বা স্ট্যাটাস পরিবর্তন; কিছু মোছা হয় না। অডিট লগে কারণ থাকে।
- **লাভ**: গড় ক্রয়মূল্য (weighted average) দিয়ে; বিক্রির সময়ের খরচ বিলে সংরক্ষিত। ক্রয় আলাদা খরচ নয়, COGS হয়ে আসে।
- **লগইন**: Firebase-ই সেশন ধরে রাখে; অ্যাপ কোনো টোকেন/পাসওয়ার্ড রাখে না। শুধু স্পষ্ট লগআউটে সেশন ও এই ফোনের ক্যাশ মোছে।
- **ডাটাবেস ফাইল** প্রতি UID-র জন্য আলাদা (`hisab_<uid>.db`)।

## ৫. পেইড সার্ভিস

কোর অ্যাপে কিছুই পেইড লাগে না। মনে রাখুন:
- Firebase **Spark** প্ল্যানে Firestore-এর দৈনিক রিড/রাইট কোটা আছে। কোটা শেষ হলে সিঙ্ক থেমে থাকে (ডাটা ফোনে নিরাপদ থাকে), পরদিন চলবে। বড় ব্যবসায় Blaze দরকার হতে পারে।
- Cloud Functions, Storage, পুশ নোটিফিকেশন (FCM সার্ভার), SMS ব্যবহার করা হয়নি। এগুলোর কোনোটি যোগ করলে খরচের হিসাব আগে দেখে নিন।

## ৬. জানা সীমাবদ্ধতা

- **প্রিন্ট**: সরাসরি প্রিন্ট বোতাম নেই। ছবি শেয়ার করে অন্য প্রিন্ট অ্যাপ দিয়ে প্রিন্ট করুন।
- **একাধিক ডিভাইসে একসাথে একই রেকর্ড সম্পাদনা**: শেষ `updatedAt` জেতে (পার্টি/পণ্য/খরচের ক্ষেত্রে)। আর্থিক রেকর্ড (বিল, পেমেন্ট, স্টক মুভ) অপরিবর্তনীয় বা শুধু যোগ হয়, তাই এগুলো হারায় না। তবে পণ্যের `গড় ক্রয়মূল্য` দুই ডিভাইসে একসাথে ক্রয় করলে সামান্য ভিন্ন হতে পারে।
- **PIN রিকভারি**: পিন ভুলে গেলে লগআউট করে আবার লগইন করতে হয় (এতে এই ফোনের আপলোড না হওয়া পরিবর্তন হারাতে পারে, অ্যাপ আগে সতর্ক করে)। বায়োমেট্রিক এখনো নেই।
- **ডিফল্ট সর্বনিম্ন স্টক**: শুধু প্রতিটি পণ্যে আলাদা করে দেওয়া যায়।
- **একাধিক স্টাফ অ্যাকাউন্ট নেই**; রুলস শুধু মালিক-UID ভিত্তিক। স্টাফ যোগ করতে হলে সদস্যপদভিত্তিক রুলস আলাদা করে লিখতে হবে।
- ক্লায়েন্ট-সাইড বলে Firestore রুলস কেবল গঠন, মালিকানা ও আর্থিক ফিল্ড অপরিবর্তনীয়তা আটকায়। ব্যালান্স যোগফল সার্ভারে যাচাই হয় না (এর জন্য Cloud Functions লাগত)।

2. **দুই অ্যাকাউন্ট**: A দিয়ে ডাটা দিন → লগআউট → B দিয়ে লগইন → A-র কিছুই দেখা যাবে না।
3. **ব্যবসা**: কাস্টমার, পণ্য (প্রারম্ভিক স্টকসহ), সাপ্লায়ার, ক্রয় (আংশিক পরিশোধ), বিক্রয় (একাধিক পণ্য, ছাড়, চার্জ, আংশিক পরিশোধ), পেমেন্ট (বেশি টাকা দিলে অগ্রিম সতর্কতা), খরচ, ফেরত, বাতিল। প্রতিবার স্টক ও বকেয়া হাতে মিলিয়ে দেখুন।
